# Gauge for Codex 1.0.0

The first public open-source release.

## What is included

- Native macOS menu-bar percentage and progress display.
- Multiple usage windows with most-constrained-window selection.
- Localized reset countdowns and exact local reset times.
- Automatic refresh, wake refresh, cached values, and stale-data warnings.
- Compact display and manual fallback.
- Universal 2 support for Apple silicon and Intel Macs.
- English, Simplified Chinese, Japanese, and Spanish.

## Installation note

This build is ad-hoc signed and is not Apple-notarized. After dragging the app to Applications, Control-click it and choose **Open** on first launch. Do not disable Gatekeeper.

## Independence

Gauge for Codex is an unofficial third-party utility. It is not affiliated with or endorsed by OpenAI.
